### 2026 / 4 / 7 — AI 版本更新公告

本次更新重点：

1. **新增 AI 助手设置面板（桌面端可视化配置）**
   - 支持直接在设置页填写：Base URL / API Key / Model / Timeout
   - 支持 OpenAI 兼容接口（`/chat/completions`）

2. **新增对局分析双阶段能力**
   - BP 阶段：阵容风险与即时动作建议
   - 进入游戏后：补全敌方信息，输出更完整策略

3. **新增 Telegram 推送能力（每局一次）**
   - 进入游戏并拿到敌方信息后，自动推送分析到 TG
   - 内置去重，避免同一局反复刷屏

4. **稳定性修复**
   - 修复设置页语言选项映射异常导致的启动报错

5. **界面风格升级（Apple-like）**
   - 更圆角、更轻玻璃感、更克制对比
   - 统一交互视觉层级，减少信息噪声

---

> 说明：本版本为 AI 预发布版本，核心目标是“可用、可配、可迭代”。
